ACTUALIZAR EL MOD EN GITHUB (version 1.1.0: clave de la IA dentro del juego)

1. Descomprime este zip.
2. En tu repositorio de GitHub: Add file -> Upload files.
3. Arrastra la carpeta "src" y el archivo "build.gradle" (los archivos con el mismo nombre se reemplazan).
   No hace falta tocar .github, ya lo tienes.
4. Commit changes.
5. Pestana Actions: espera a que el Build salga en verde y descarga el artefacto "corazon-de-melon".
6. Dentro esta corazon-de-melon-1.1.0.jar.

EN MINECRAFT
- BORRA el jar viejo (corazon-de-melon-1.0.0.jar) de la carpeta mods. Si dejas los dos, Forge falla.
- Pon el jar nuevo (1.1.0).
- Abre el juego, entra a un mundo y pulsa la tecla K (o Mods -> Corazon de Melon -> Config).
- Elige proveedor (Groq), pega tu clave con Ctrl+V y pulsa Guardar.
- Prueba con /mao hola.
